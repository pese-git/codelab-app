Prompt queue — messages sent while the session is busy
SessionStateMachine._startTurn already rejects a new turn while a session is runningTurn/awaitingApproval (state_machines.dart:793-795) — correct today. But submitPrompt() doesn't check this first: it adds the message to the transcript, tries to send, shows "Prompt failed" — and the composer already cleared the text. This queue avoids the failed attempt entirely.
