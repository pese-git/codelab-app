# 10. Риски

> Часть предложения [«Dart-агент и клиенты CodeLab»](../dart-agent-and-clients.md). Status: Proposed. Исходные решения, связанные документы и порядок чтения — в оглавлении.

← [9.15. Этап 10 — Мобильные и web](09-15-stage-10-mobile-web.md) · [Оглавление](../dart-agent-and-clients.md) · [11. Допущения и открытые вопросы](11-assumptions-and-open-questions.md) →

| Риск | Вероятность | Влияние | Снижение |
|---|---|---|---|
| Объём работ недооценён | высокая | высокое | MVP ограничен этапами 4 и 6; Context Manager, multi-agent и полноэкранный TUI вне MVP; готовность измеряется матрицей целей и автоматической проверкой доказательств (§9.14), а не «на глаз» |
| Пробелы экосистемы Dart: tree-sitter, точный токенайзер, MCP SDK | средняя | среднее | токены — эвристика «символы / 4» с якорем по usage провайдера; MCP — свой клиент (протокол простой; готовые пакеты pub.dev проверить на этапе 8); tree-sitter — FFI только на десктопе и только после закрытия целей Must |
| Потеря широты провайдеров LiteLLM | средняя | низкое | LiteLLM Proxy как OpenAI-совместимый `baseUrl`; документировать |
| Два агента одновременно — двойная нагрузка на сопровождение | высокая | среднее | Python-агент заморожен, кроме критических исправлений безопасности; новые функции — только в Dart |
| Дисциплина «чистого ядра» нарушится ради удобства | средняя | высокое | тест-сторож импортов и allowlist зависимостей, сборка ядра в web — с этапа 0, обязательные джобы CI |
| Разделение `acp_transports` (этап 0) ломает импорты app и тестов | средняя | низкое | механическое изменение под защитой 8 интеграционных тестов; классы конфигурации остаются в основном бареле |
| Встроенное ядро замедляет UI (тяжёлые операции в UI-isolate) | средняя | среднее | разбор журнала и сжатие — в `Isolate.run`; замер на этапе 7; при плохом замере ядро в отдельном isolate (in-process транспорт это допускает) |
| Общие изменяемые `Map` между клиентом и агентом в одном процессе | средняя | среднее | глубокая копия JSON-дерева в `InProcessAcpLink` по умолчанию (`copyMessages = true`); отключение копии — только по замеру |
| Расхождения ACP-поведения с Zed после переписывания | низкая | среднее | ручная проверка с Zed на этапах 4 и 9; golden-фикстуры ACP |
| Выделение `acp_client_kit` из `CodeLabShellCubit` сломает поведение app | средняя | среднее | этап 5 — сначала фасад с сохранением API и состояния под защитой 8 интеграционных тестов; исправления поведения — отдельным change с собственными тестами |
| Логика клиентов снова расползётся по UI-слоям | средняя | среднее | сторож: `acp_client_kit` без Flutter и `dart:io`; правило ревью «логика — в kit, в Cubit/REPL — только отображение» |
| Перенос лишней сложности (супервизоры, все возможности профиля, структурное сжатие) раньше, чем она нужна | средняя | среднее | в этап входят только подсистемы, отмеченные этим этапом в §4.0; остальное — по матрице целей |
| Фикстуры закрепляют неверное прочтение спецификации ACP | средняя | высокое | ссылка на раздел спецификации в каждой фикстуре; изменение фикстуры — только через ревью владельца ACP-границы; ручная проверка с Zed и Claude Code ACP |
| Функция текущего CodeLab не попала в цели и потерялась | средняя | среднее | блок «не регрессировать» в матрице целей, составленный по анализу CodeLab и OpenSpec specs Python-агента |
| Конфликт имени команды `codelab` (сейчас Python-агент, после — CLI) | высокая | низкое | до этапа 9 бинарь CLI не устанавливается под общим именем; на этапе 9 — алиас `codelab serve` на один релиз и смена профиля по умолчанию в app |
| Терминальные различия (Windows Console, tmux, не-TTY) ломают REPL | средняя | среднее | построчный режим как запасной; PTY-тесты на macOS и Linux; ручная проверка на Windows перед релизом |
| Молодая зависимость TUI `dart_tui` (3.0.0 от 2026-10-17, три мажорные версии, один издатель): ломающие изменения, неподтверждённая работа на Windows, нет тестового стенда, нативная часть через `dart:ffi` (§12.2.12) | средняя | среднее | пакет только в `apps/codelab_cli/lib/src/tui/` (сторож), чистые `reduce`/`render` без него; `^3.0.0`, мажорные обновления — отдельным PR с PTY-тестами; разведка 6.11 по чек-листу §12.2.7; запасной путь — свой рендер за тем же ядром экрана; TUI вне MVP, построчный REPL от пакета не зависит |
| Нарушение лицензии или атрибуции при воспроизведении внешних алгоритмов | низкая | высокое | правила §7а, `THIRD_PARTY_NOTICES.md`, пункт в шаблоне PR |
| Пользователь на канале `pinned` остаётся на отозванной версии без уведомления (§12.7.3) | низкая | высокое | закрепление — осознанный выбор пользователя; отзыв записывается в `RELEASE_NOTES.md` следующей версии и на странице загрузки; предупреждение `codelab update --check` на `pinned`, если версии нет в манифестах каналов, — доработка после U-29 |
