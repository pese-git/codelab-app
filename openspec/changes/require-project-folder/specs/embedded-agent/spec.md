## ADDED Requirements

### Requirement: Проектный конфиг сессий встроенного агента
`localEmbeddedAgentOpener` SHALL передавать ядру порт `ProjectConfigLoader` — тот же `FileConfigSource`, что источник перезагрузки, с тем же окружением. Сессия вне папки открытия тогда получает конфигурацию и функцию модели своей папки (spec agent-runtime «Конфигурация сессии вне корня запуска»; design.md change `require-project-folder`, D21). Папка из `open` остаётся корнем запуска: из неё берутся ключи процесса (`HostSettings`: бэкенд секретов, журнал сессий, логи), а хранилище секретов и HTTP-клиент общие для всех сессий. `modelsFor` открывателя SHALL строить функцию модели и для сессий других папок. `scriptedEmbeddedAgentOpener` порт НЕ SHALL передавать.

#### Scenario: Сессия другой папки получает свои запреты
- **WHEN** встроенный агент открыт для `/A`, доверенный проект `/B` задаёт `permissions.tools.exec: deny`, и клиент создаёт сессию с `cwd: /B`
- **THEN** вызов `exec` в этой сессии запрещён правилом проекта `/B`
