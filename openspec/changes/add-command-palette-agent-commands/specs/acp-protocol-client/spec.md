## ADDED Requirements

### Requirement: Обновления сразу после session/new
CodeLab SHALL применять к новой сессии `session/update` с её `sessionId`, пришедшие после ответа на `session/new`, но до того, как клиент завёл сессию, — в порядке прихода и до публикации сессии. Пока ни один `session/new` не ожидает ответа, обновления неизвестных сессий SHALL отбрасываться, как прежде; обновления сессий, которые так и не были созданы, НЕ SHALL заводить сессию.

#### Scenario: Команды агента сразу за ответом
- **WHEN** агент отвечает на `session/new` и следом, тем же пакетом транспорта, присылает `available_commands_update` для этой сессии
- **THEN** созданная сессия содержит объявленные команды

#### Scenario: Чужая неизвестная сессия
- **WHEN** во время `session/new` приходит `session/update` для другого, неизвестного `sessionId`
- **THEN** сессия с этим id не появляется, а новая сессия не получает этого обновления
