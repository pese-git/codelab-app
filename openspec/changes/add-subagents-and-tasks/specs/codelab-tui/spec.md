## ADDED Requirements

### Requirement: Субагенты и список задач в TUI
Зона одобрения (требование «Одобрение в TUI») для запроса с `PendingApprovalView.subagent` SHALL показывать строку пути `<путь> wants to run` (например `review › explore wants to run`, D27) и заголовок задачи спрашивающего приглушённо; клавиши и варианты прежние. Строки `agent` в транскрипте при этом не раскрываются.

`TaskOpsItem` SHALL показываться в транскрипте одной приглушённой строкой с иконкой списка и текстом kit (например `Tasks #1–#4 added to the plan`), без рамки и статуса; неуспешная операция — обычной строкой вызова с причиной (D27).

Строка вызова `agent` в транскрипте SHALL показывать:
- пока вызов идёт: без вызовов потомков — последнюю строку прогресса; с вызовами потомков (этап 2) — «хвост» (D25, артборд C16): три последних вызова потомков с глифом статуса, меткой и деталью и строку `+N more tool calls · Nk tokens`;
- после завершения — статус с итогом `Done (4 tool calls · 18.2k tokens · 48s)` (так же `Failed (…)`, `Cancelled (…)`) из `subagentSummary` (D24), без итога — только статус; раскрываемый отчёт, как текстовый вывод других вызовов.

Раскрытая строка `agent` SHALL показывать все вызовы потомков вложенными строками с отступом по глубине.

Список задач SHALL показываться блоком над композером (D26, артборд C16): заголовок `Tasks <c>/<n> done · ctrl+t hide` и строки пунктов в формате REPL. Действие `toggle_tasks` (Ctrl+T) SHALL прятать блок до одной строки `Tasks <c>/<n> done · ctrl+t show` и показывать снова; строка помощи SHALL содержать `ctrl+t tasks`. До первого `plan` блока нет. Доска фоновой работы (этап 5) Ctrl+T НЕ SHALL открывать — только команда `/tasks`.

План в транскрипте SHALL печататься тем же форматом, что в REPL (`codelab-cli`, «Субагенты и список задач в REPL»).

#### Scenario: Одобрение ребёнка в TUI
- **WHEN** в `--ui tui` ребёнок `review` просит команду
- **THEN** зона одобрения содержит строку `review wants to run`, заголовок задачи и команду; выбор варианта уходит в этот запрос

#### Scenario: Итог в статусе
- **WHEN** вызов `agent` завершается с `summary` 4 вызовов, 18 200 токенов и 48 с
- **THEN** строка вызова показывает `Done (4 tool calls · 18.2k tokens · 48s)`

#### Scenario: Ctrl+T прячет список задач
- **WHEN** агент прислал `plan` из четырёх пунктов, два `completed`, и пользователь дважды нажимает Ctrl+T
- **THEN** сначала блок над композером с заголовком `Tasks 2/4 done · ctrl+t hide` и четырьмя строками, после первого нажатия — одна строка `Tasks 2/4 done · ctrl+t show`, после второго — снова полный блок; композер и ввод не теряют фокус
