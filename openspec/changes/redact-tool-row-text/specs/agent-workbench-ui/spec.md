## ADDED Requirements

### Requirement: Вывод раскрытой строки инструмента без секретов
Раскрытая строка вызова инструмента в ленте app SHALL показывать вывод только из `ToolRowFormatter.outputTail` с пределом строк хвоста ленты (20), а не сырые текстовые элементы вызова. Вторая строка и хвост вывода SHALL показываться без секретов. Однострочная ошибка НЕ SHALL показываться дважды, а строка вывода, которой нет во второй строке, НЕ SHALL пропадать.

#### Scenario: Упавший fetch с паролем в ошибке
- **WHEN** пользователь раскрывает строку `fetch`, упавшего с единственной строкой вывода "Error: request to https://user:pass@host/x failed"
- **THEN** под строкой одна строка `Error: request to https://<redacted>@host/x failed`, и строки `pass` в раскрытой строке нет

#### Scenario: Вывод успешного вызова замаскирован
- **WHEN** пользователь раскрывает строку завершённого `read` с выводом "API_KEY=sk-live-123\nDEBUG=1"
- **THEN** под строкой вывод `API_KEY=<redacted>` и `DEBUG=1`, строки `sk-live-123` нет
