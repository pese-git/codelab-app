## Why

Документация на сайте (change `add-astro-site`, архив 2026-11-18) собирается из репозитория без копий и группируется по пути файла (D9). Документов стало около двухсот, и правило D9 «`README.md` первым, остальные по заголовку» перестало помогать читателю. Состояние на 2026-11-26 (проверено на сборке `develop`):

- **Порядок глав потерян.** Боковое меню сортирует документы по алфавиту заголовков. Номера глав из имён файлов (`doc/user/NN-<тема>.md`, `doc/NN-<тема>.md` — схема `.claude/skills/codelab-docs/SKILL.md` §3) не учитываются. У `codelab` 13 глав руководства пользователя и 17 документов разработчика идут одним списком: первым стоит «Диалог», «Обзор» — в середине, рядом стоят «Полноэкранный режим» и «Полноэкранный режим (TUI)» из разных руководств. У CodeLab app так же перемешаны 11 и 15 документов, у агента — 12 и 8.
- **Мобильный экран.** На ширине 375 px весь список раздела стоит выше текста: заголовок документа начинается примерно на 1211 px.
- **Оглавление `/docs/`** — стена ссылок. Группа «Пакеты» — 147 пунктов (133 главы и 14 README) одним списком.
- **Нет ориентиров на странице:** нет поиска, переходов «назад / далее» между главами, «хлебных крошек», кнопки копирования кода; оглавление «На этой странице» не показывает текущий раздел.

Пользователь согласовал направление (обсуждение 2026-11-26): порядок из имени файла, подгруппы по аудитории, мобильное меню, переходы между главами, крошки, оглавление по ролям, поиск и два небольших скрипта.

## What Changes

- **Порядок глав из имени файла.** Внутри подгруппы — вход (`README.md`, `user-guide.md`, `development.md`), затем главы с префиксом `NN-` по номеру, затем остальные по заголовку. Номер виден в меню: «03 · Полноэкранный режим». Документ без префикса не ломает сборку (D1).
- **Подгруппы по аудитории** внутри приложения, по пути файла: «Руководство» (`doc/user-guide.md`, `doc/user/**`), «Эксплуатация» (`doc/operations.md`), «Для разработчика» (остальное в `doc/`). Вложенный каталог `doc/<каталог>/` — своя подгруппа с заголовком его `README.md`. Пакеты в меню страницы — по одному пакету, а не все 147 документов (D2).
- **Слой пакета по имени** (ADR-0002) без ручного списка: `codelab_acp_*` — «Протокол ACP», `codelab_client_*` — «Клиент», `codelab_agent_*` — «Агент», прочие `packages/dart/*` — «Мосты и служебные пакеты», `packages/flutter/*` — «Интерфейс Flutter», пакеты только с тестами `codelab_*_tests` (сторож `codelab_architecture_tests`) — «Проверки». Неизвестное расположение — «Другие пакеты», без ошибки сборки (D3).
- **Мобильное меню.** На узком экране меню раздела свёрнуто в `<details>` «Документы раздела (N)» над статьёй. Работает без JavaScript; заголовок документа виден на первом экране (D4).
- **«Хлебные крошки»** над заголовком: «Документация › группа › [пакет ›] подгруппа», ссылки ведут на оглавления (D5).
- **«Назад / Далее»** внизу документа — соседние документы той же подгруппы (D5).
- **Оглавление `/docs/` по ролям:** «Начать работу», «Пользоваться», «Развернуть и разрабатывать». Главы приложений свёрнуты в `<details>`. Пакеты — по слоям, только README с описанием; главы пакета — в меню его страниц (D6).
- **Скрипты страниц документации:** кнопка копирования у блоков кода и подсветка текущего раздела в «На этой странице». Правило скриптов витрины (D2 `redesign-site-showcase`) распространяется на документацию; бюджет 12 КБ gzip — на всю страницу (D7).
- **Поиск по документации** на Pagefind: статический индекс после `astro build`, без чужих хостов, с русским языком. Рантайм поиска загружается только по действию в поле поиска; без JavaScript поля нет, есть ссылка на оглавление. Новая npm-зависимость `pagefind` (MIT) — с явным решением о лицензии, бюджете, CSP и CI (D8).
- **Проверка сборки** (`check-links`): бюджет называется бюджетом JavaScript страницы; файлы поиска не подключаются статически из HTML (D7, D8).
- **Skill `codelab-site`** (§1, §6, §7, §8, §9) и `codelab-docs` §3 — после одобрения change (задачи `[orchestrator]`).

## Что НЕ входит

- **Адреса документов не меняются** (D4 `add-astro-site`): внешние и внутренние ссылки не ломаются. Новых страниц в адресном пространстве `/docs/<путь>/` нет.
- **Документы не правятся под сайт.** Frontmatter, ручные списки порядка и метки аудиторий не вводятся: всё выводится из путей и номеров файлов. Переименование файлов документации ради сайта не входит.
- Хостинг, CSP-заголовки и публикация — этап хостинга (вопросы H1–H3 `add-astro-site`). Здесь только фиксируется, что поиску нужен `'wasm-unsafe-eval'` в `script-src`: пользователь принял это 2026-11-26, требование передаётся change хостинга (D8, R1, D13).
- Фильтры поиска, поиск по новостям и страницам возможностей, подсветка найденного на целевой странице.
- Публикация новых источников документации (allowlist `publish.ts` не меняется).
- Изменения продуктов, ACP, пакетов и приложений workspace.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `project-site`: требование «Разделы сайта» уточняет навигацию документации; новые требования — порядок и подгруппы документации, навигация на странице документа, оглавление по ролям, скрипты страниц документации, поиск.

## Impact

- **Код:** `site/**` — `src/lib/nav.ts` (порядок, подгруппы, слои, соседи, крошки), новый `src/lib/docs-index.ts` (оглавление по ролям), `src/lib/doc-page/` и `src/scripts/doc-page/` (копирование, подсветка оглавления, поиск), компоненты `src/components/docs/`, страницы `src/pages/docs/index.astro` и `[...path].astro`, стили `src/styles/base.css`, `scripts/check-links.mjs`, `package.json` и `package-lock.json` (зависимость `pagefind`, шаг индексации в `build`).
- **Пакеты и приложения workspace:** не меняются. Граф зависимостей в `README.md` и правила сторожа (`rules.dart`, `pubspec_allowlist_test.dart`) не меняются.
- **ACP:** не затрагивается.
- **Зависимости npm:** одна новая — `pagefind` (MIT) с платформенными бинарями `@pagefind/<платформа>` через `optionalDependencies`, без install-скриптов (D8).
- **CI:** охват джоба `site` (`tool/ci/ci_scope.dart`) не меняется; `npm run build` дополнительно индексирует `dist/`.
- **Документы:** `.claude/skills/codelab-site/SKILL.md`, `.claude/skills/codelab-docs/SKILL.md` §3. Опубликованные документы не меняются.
