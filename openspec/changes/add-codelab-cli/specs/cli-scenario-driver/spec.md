## ADDED Requirements

### Requirement: Команда test-scenario
`codelab test-scenario <файл-или-папка>... --agent <профиль> [--filter <glob по id>] [--timeout <длительность>]` SHALL проигрывать golden-фикстуры ACP (формат `agent-core-architecture` §14, загрузчик `codelab_acp_testing`) против агента, которого задаёт профиль подключения, через `runAgentFixtureOver` (H-04). Для каждой фикстуры SHALL:
1. пропускать фикстуру без роли `agent` с пометкой `SKIP` и причиной;
2. запускать агента по профилю заново для каждой фикстуры; для профиля `stdio:`, команда которого — `codelab-agent`, блок `llm` фикстуры SHALL записываться во временный файл и передаваться флагом `--llm-script`; для другого агента фикстура с блоком `llm` SHALL пропускаться с причиной;
3. проигрывать кадры клиента и сравнивать нормализованные кадры агента по правилам корпуса; при первом расхождении — `FAIL` с диффом ожидаемого и фактического кадра.

`--timeout` (по умолчанию `30s`) SHALL ограничивать ожидание кадра агента. Профиль `embedded` до этапа 7 SHALL давать код `64`.

#### Scenario: Корпус против агента-повторителя
- **WHEN** `test-scenario` запускается на корпусе против `FixtureReplayAgent`
- **THEN** каждая фикстура с ролью `agent` даёт `PASS`, остальные — `SKIP`, код выхода `0`

#### Scenario: Испорченный ожидаемый кадр
- **WHEN** у фикстуры изменён ожидаемый кадр агента
- **THEN** строка фикстуры — `FAIL` с диффом кадров, код выхода `1`

#### Scenario: Фильтр
- **WHEN** передан `--filter 'acp/session-*'`
- **THEN** проигрываются только фикстуры с подходящим id

### Requirement: Вывод и коды выхода test-scenario
Драйвер SHALL печатать в stdout строку `PASS|FAIL|SKIP <id> (<время>)` на фикстуру в порядке id, дифф `FAIL` — под строкой фикстуры, и итог `<passed> passed, <failed> failed, <skipped> skipped`. Код выхода SHALL быть `0`, если `FAIL` нет; `1`, если есть хотя бы один `FAIL` или агент не запустился; `64` — ошибка использования (нет пути, путь не существует, неверный профиль, битый файл фикстуры).

#### Scenario: Битая фикстура
- **WHEN** путь указывает на файл, который не проходит загрузчик фикстур
- **THEN** в stderr — путь и причина `FixtureFormatException`, код выхода `64`
