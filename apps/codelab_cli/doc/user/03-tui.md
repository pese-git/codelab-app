# Полноэкранный режим

Полноэкранный режим рисует транскрипт, строку ввода, подсказки и статус-строку в отдельном экране терминала. Сессия, команды `/…`, очередь и разрешения — те же, что в [диалоге](02-repl.md). Глава объясняет раскладку экрана, клавиши и экраны выбора, настроек и мастера провайдера. Оглавление руководства — [руководство пользователя](../user-guide.md).

## Запустить

```bash
codelab --ui=tui
```

Флаги `-c`, `-r`, `-C`, `-m`, `--mode`, `-a` работают так же, как в диалоге: например, `codelab --ui=tui -c` открывает последнюю сессию папки и показывает её транскрипт.

Полноэкранный режим работает только в терминале: если stdin или stdout перенаправлены, `codelab` завершится с ошибкой `--ui tui needs a terminal on stdin and stdout`. С `-p` флаг `--ui=tui` не сочетается: `--ui applies only to the interactive mode`.

## Раскладка экрана

Внизу — строка ввода, строка подсказок и статус-строка: профиль агента, режим, модель, а если агент сообщает расход — заполнение контекста (`ctx 9%`), токены сессии (`↑3.0k ↓7`) и стоимость (`$0.13`). От 80 % контекста сегмент жёлтый, от 95 % красный; «~» перед числом — оно приблизительное. На узком экране сегменты пропадают в таком порядке: профиль, стоимость, токены, контекст; затем модель сокращается до части после последнего `/`, а потом пропадает. Режим, `queue: N` и `approval pending` остаются; если не помещаются и они, строка обрезается с `…`. Над ними — транскрипт; список задач агента показывается над строкой ввода.

Нижняя часть экрана после команды `/profile` (кадр 120×40, `tmux capture-pane`):

```text
> /profile
Profile embedded (Embedded agent): embedded embedded-cli
>
Enter send · Shift+Enter/Alt+Enter new line · Esc/Ctrl+C cancel · PgUp scroll · ctrl+t tasks · ctrl+o details
embedded · standard · lmstudio/qwen/qwen3-1.7b · ↑13.9k ↓1.2k
```

<!-- screenshot: PNG окна codelab --ui=tui во время хода агента — apps/codelab_cli/doc/images/tui-turn.png -->

Подсказки, которые не помещаются по ширине окна, отбрасываются с конца строки. Полный набор в широком окне заканчивается так: `ctrl+t tasks · ctrl+o details · Ctrl+D exit`.

Пока агент работает, в статус-строке перед профилем появляются значок хода и время в секундах.

## Клавиши

Клавиши полноэкранного режима отличаются от построчного:

| Клавиша | Что делает |
|---|---|
| Enter | отправить; во время ответа — поставить в очередь |
| Shift+Enter, Alt+Enter | новая строка (Shift+Enter работает, если терминал отличает его от Enter); `\` в конце строки и Enter тоже вставляют перевод строки. Ctrl+J новой строкой не является |
| PgUp, PgDn | прокрутить транскрипт; пока он прокручен вверх, внизу видно `↓ N new` |
| End | вернуться к последней строке и снова следовать за выводом |
| Esc | во время ответа — отменить ответ; иначе — очистить строку ввода |
| Ctrl+C | во время ответа — отменить ответ; иначе — очистить строку, второе нажатие за 1 секунду — выход |
| Ctrl+D | выход на пустой строке |
| Ctrl+A, Ctrl+E | курсор в начало и в конец строки; Home тоже идёт в начало, а End в полноэкранном режиме занят прокруткой, поэтому в конец строки — только Ctrl+E |
| Ctrl+T | спрятать список задач над строкой ввода до одной строки `Tasks <c>/<n> done · ctrl+t show` и показать снова |
| Ctrl+O | раскрыть или свернуть сразу все строки субагентов в транскрипте |

- Свёрнутая строка субагента показывает статус, а у работающего субагента — три последних шага его потомков и `+N more tool calls`. Раскрытая показывает все шаги потомков с отступом `↳` и отчёт субагента (до 20 строк). Что такое субагенты — в [главе агента о субагентах](../../../codelab_agent/doc/user/07-subagents-and-tasks.md).
- Вставка из буфера не отправляет запрос сама: текст появляется в строке ввода целиком.
- Tab после `/` дополняет имя команды.

Выход — Ctrl+D на пустой строке, `/exit` или двойной Ctrl+C. После выхода терминал возвращается в обычный экран.

## Списки выбора

`/model`, `/mode` и `/sessions` без аргумента открывают список с курсором на текущем значении: ↑ и ↓ выбирают пункт, `/` включает фильтр, Enter применяет, Esc закрывает без запроса к агенту.

```text
> /mode
Mode (mode):

  plan  Plan
  ask  Ask
› standard  Standard
  accept-edits  Accept edits
  bypass  Bypass
5 items
>
```

## Настройки и мастер провайдера

В полноэкранном режиме работают `/provider` и `/settings`, как и в диалоге:

- `/provider add` открывает мастер поверх экрана — те же шаги, что у [мастера первого запуска](01-install-and-first-run.md#первый-запуск). `/provider list` и `/provider remove` печатают результат в транскрипт.
- `/settings` открывает экран настроек: слева разделы (`Models`, `Agent`, `Providers`, `Permissions`, `Budget`, `Subagents`, `MCP`, `Logging`), справа строки `ключ значение источник`.

```text
> /settings
Settings · /settings · user ~/.codelab/config.yaml

                   key · value · source
› Models       │ › agent.default_model  lmstudio/qwen/qwen3-1.7b  user
  Agent        │   providers.lmstudio.models.qwen/qwen3-1.7b.context_window  32768  user
  Providers    │   providers.lmstudio.models.qwen/qwen3-1.7b.max_output_tokens  (not set)  default
  Permissions  │   providers.lmstudio.models.qwen/qwen3-1.7b.name  (not set)  default
  Budget       │   providers.lmstudio.models.qwen/qwen3-1.7b.image  false  default
  Subagents    │   providers.lmstudio.models.qwen/qwen3-1.7b.reasoning  false  default
  MCP          │   providers.lmstudio.models.qwen/qwen3-1.7b.cost_input  (not set)  default
  Logging      │   providers.lmstudio.models.qwen/qwen3-1.7b.cost_output  (not set)  default
               │   …

↑↓ move · enter edit · ←→ choose · tab section · r reset · esc close
embedded · standard · lmstudio/qwen/qwen3-1.7b
```

Клавиши экрана — в его нижней строке: ↑ и ↓ двигают курсор, Enter правит значение, ← и → выбирают из списка, Tab переходит к следующему разделу, `r` сбрасывает значение, Esc закрывает. Пока экран открыт, ход агента не отменяется, а запрос разрешения ждёт: в статус-строке видно `approval pending · esc to answer`. Поле правки на этом экране показывает значение как есть, без маски: секреты через него не вводят. В нижней строке при правке — `enter save · ctrl+u save to user · esc cancel`: Enter сохраняет значение туда, откуда оно взято: значение из `default` или `user` — в файл пользователя, значение из файла проекта — в локальный файл проекта (если у агента есть такой слой, иначе экран отказывает). Ctrl+U всегда сохраняет в файл пользователя, Esc отменяет. Значение, заданное внешним файлом или окружением, здесь не меняется. Очистить поле — Backspace.

В мастере `/provider add` ключ при вводе показывается звёздочками, а Ctrl+R показывает и прячет его.
