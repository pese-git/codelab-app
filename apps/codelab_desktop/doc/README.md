# Документация CodeLab app

Оглавление всех документов настольного приложения `codelab_desktop`. Документы разделены по тому, кто их читает: пользователь, тот, кто собирает и сопровождает, и разработчик, который меняет код. Короткий вход в приложение — [README приложения](../README.md).

## Для пользователя

- [Руководство пользователя](user-guide.md) — оглавление глав: первый запуск, проекты и сессии, диалог с агентом, запросы разрешений, файлы, терминал и палитра команд, подключение и провайдеры, расширения агента, настройки, что делать при сбоях. Главы лежат в каталоге [`user/`](user/00-overview.md), по одной на тему.

## Для DevOps

- [Эксплуатация](operations.md) — сборка под macOS, подпись, где лежат данные и логи, переменные окружения, события журнала, сеть и безопасность, выход из приложения.

## Для разработчика

[Разработка](development.md) — краткий обзор: место в monorepo, карта кода, поток запуска, рецепты, тесты. Руководство по главам углубляет его; при расхождении прав код, а затем глава.

### Порядок чтения

Для первого знакомства читайте подряд:

1. [Начало работы](00-getting-started.md) — подготовка, запуск, отладка, тесты.
2. [Обзор приложения](01-overview.md) — фичи, слои, правила зависимостей, словарь.
3. [Composition root](02-composition-root.md) — как всё собирается и закрывается.
4. [Путь состояния](03-state-flow.md) — как состояние клиентского слоя доходит до виджетов.

Остальные главы читайте по нужной теме, в любом порядке.
