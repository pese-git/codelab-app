# Документация `codelab-agent`

`codelab-agent` — Dart-агент CodeLab как отдельная программа: `serve --stdio`, `serve --ws` и команды настройки `config`, `provider`, `mcp`, `secret`. Здесь собраны документы для тех, кто его запускает, и для тех, кто меняет его код. Вход для всех — [README приложения](../README.md).

## Документы

| Я хочу… | Читать |
|---|---|
| узнать, что умеет агент, и пользоваться им: инструменты, разрешения, контекст проекта, MCP, сессии | [Руководство пользователя](user-guide.md): двенадцать глав в [`user/`](user/00-overview.md) |
| собрать, запустить на сервере или в CI, понять логи и коды выхода | [Эксплуатация](operations.md): сборка, схема развёртывания, `serve --stdio` и `--ws`, флаги, переменные, секреты, логи, коды выхода, безопасность |
| начать работать с кодом, увидеть карту `lib/` и поток запуска | [Разработка](development.md): начало работы, место в monorepo, структура, отладка, правила |
| понять, как бинарь превращает аргументы в сервер | [Устройство](internals.md): порядок запуска, разбор аргументов, слой флагов, режимы `AgentHost`, транспорты, сигналы, логи, подкоманды |
| прогнать тесты, написать процессный тест или тест хоста | [Тестирование](testing.md): скрипты Melos, карта тестов, помощники, скелеты |
| добавить флаг `serve`, подкоманду, событие лога | [Рецепты](recipes.md): флаг на примере `--max-steps`, подкоманда, сужение профиля, событие лога |
| разобраться с ошибкой при разработке | [Частые проблемы](troubleshooting.md) |

Порядок для первого знакомства с кодом: [Разработка](development.md), затем [Устройство](internals.md). Остальное читайте по теме.
