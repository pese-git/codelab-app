# Модель и провайдеры

Агент сам не думает: ответы пишет модель, к которой он обращается через провайдера. После этой главы вы знаете, как агент выбирает модель, как её сменить и какие лимиты ограничивают ход. Подробная схема файлов и примеры (LiteLLM Proxy, LM Studio, Ollama) — в [настройке агента](../../../../docs/user/configuration.md); здесь они не повторяются.

## Провайдер и модель

Провайдер — сервис, который отвечает на запросы к модели: у него адрес, способ авторизации и список моделей. Рабочих видов провайдеров два:

| `kind` | Что это |
|---|---|
| `openai-compatible` | любой сервис с интерфейсом, совместимым с OpenAI: сам OpenAI, LiteLLM Proxy, LM Studio, Ollama; `base_url` обязателен |
| `anthropic` | Anthropic; `base_url` по умолчанию `https://api.anthropic.com` |

Значение `kind: gemini` схема и команда `provider add` принимают, и `config check` его не отвергает, но адаптера Gemini в агенте нет: первый запрос к такой модели завершается ошибкой `<имя провайдера>: provider api gemini is not supported yet`. Пользуйтесь `openai-compatible` или `anthropic`.

Модель называют как `<id провайдера>/<id модели>`, например `local/qwen/qwen3-1.7b`. Провайдеры и модели записаны в `providers` файла `config.yaml`. Модель, которой нет в `providers.<id>.models`, агент не примет.

Как добавить провайдера и ключ — [шаг 1 и шаг 2 настройки](../../../../docs/user/configuration.md#шаг-1-подключите-провайдера-и-модель); в app и `codelab` для этого есть мастер, в `codelab-agent` — команда `provider add` ([установка и запуск](01-install-and-run.md#подключить-модель)). Список провайдеров:

```bash
codelab-agent provider list
```

```text
Secrets: env (OS keychain backends are not available in this version; set secrets.backend: file or CODELAB_SECRET_* variables)
local  kind: openai-compatible  base_url: http://127.0.0.1:1234/v1  models: qwen/qwen3-1.7b  key: none
```

## Как агент выбирает модель новой сессии

Агент идёт по цепочке и берёт первое, что нашёл:

1. Явная модель: ключ `agent.default_model` или флаг `--model` у `serve`.
2. Модель, которую вы выбрали в прошлый раз. Агент запоминает явный выбор.
3. Первая модель первого провайдера в конфигурации.

`codelab-agent config check` печатает итог и источник: `(config)`, если модель задана ключом, и `(first-provider)`, если взята первая:

```text
Sources: defaults, ~/.codelab/config.yaml
Default model: local/qwen/qwen3-1.7b (first-provider)
Config: valid
```

Сессия, которую вы открываете заново, возвращается к модели из своего журнала, если эта модель ещё есть в конфигурации.

## Сменить модель

- В клиенте — селектором модели, если он есть, или командой `/model <провайдер/модель>` в поле ввода. Команда `/model` встроена в агента. В `codelab` её перекрывает одноимённая команда клиента, а команда агента доступна как `/agent:model`.
- Для новых сессий — ключом `agent.default_model`:

  ```bash
  codelab-agent config set agent.default_model local/qwen/qwen3-1.7b
  ```

  Команда проверяет значение и отказывает, если модели нет в каталоге: `local/nope is not in the model catalog; declare it in providers.local.models`.

## Рассуждение

Ключ `agent.effort` — начальный уровень рассуждения новой сессии: `low`, `medium` (по умолчанию) или `high`. Влияет на модели, которые умеют рассуждать; поддержку рассуждения у модели задаёт её запись в каталоге (`providers.<id>.models.<модель>.reasoning`). Начальный уровень новых сессий app показывает на странице настроек — [руководство app](../../../codelab_desktop/doc/user/04-permissions.md#режим-разрешений-и-рассуждение-новых-сессий).

## Лимиты хода

Ход — всё, что агент делает в ответ на одно ваше сообщение: несколько запросов к модели и вызовов инструментов подряд. Чтобы ход не длился бесконечно, у него есть бюджет.

| Ключ | Что ограничивает | По умолчанию |
|---|---|---|
| `budget.max_steps` | запросы к модели за ход | `50` |
| `budget.max_tokens` | сумма входных и выходных токенов за ход | без предела |
| `budget.max_cost` | стоимость хода в долларах; работает только для моделей с известной ценой | без предела |
| `budget.max_duration` | время хода; время ожидания ваших ответов на вопросы не считается | без предела |

Лимит шагов можно задать и при запуске: флаг `--max-steps` или переменная `CODELAB_MAX_STEPS` у `codelab-agent serve`. Эти ключи читаются при каждом ходе, поэтому правка действует со следующего хода.

Отдельно действует лимит ответа модели `max_output_tokens`. Если он не задан в записи модели и модели нет во встроенном каталоге, провайдеру уходит `4096`, а в stderr агента появляется предупреждение `llm.catalog.default_used`. Если ход обрывается заметкой «The model reached its token limit, so the turn ended.», увеличьте значение — [подробности](../../../../docs/user/configuration.md#шаг-1-подключите-провайдера-и-модель).

Умолчания бюджета, субагентов и сжатия можно менять и в app: страница настроек «General», блок «Agent defaults» — [руководство app](../../../codelab_desktop/doc/user/09-settings.md#умолчания-агента).

## Чего пока нет

Ключи `agent.fallback` (запасные модели) и `agent.summary_model` (отдельная модель для резюме при сжатии) схема принимает, но агент их не применяет: запасные модели не включаются, резюме пишет модель сессии. `codelab-agent config check` предупредит: `agent.fallback: this key is read but not applied by this version of the agent`.
