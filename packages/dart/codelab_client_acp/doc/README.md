# Руководство по `codelab_client_acp`

Руководство для разработчика объясняет, как устроен протокольный клиент ACP `codelab_client_acp`: как ядро `AcpClientApplication` ведёт соединение, сессии и ходы, как отвечает на запросы агента (`session/request_permission`, `fs/*`, `terminal/*`) и как не выпускает агента за рабочую папку сессии. Прочитав его, вы понимаете путь `session/prompt` и `session/update` от хоста до агента и обратно, знаете, где проверяется ограничение рабочей папкой, и можете добавить новый вид обновления или новый запрос агента.

Руководство описывает код как он есть. Нормы лежат в спецификациях [`openspec/specs/`](../../../../openspec/specs/) (`acp-protocol-client`, `acp-fs-client`, `acp-terminal-client`, `acp-client-kit`) и в инвариантах [`AGENTS.md`](../AGENTS.md) пакета. Если код и это руководство спорят — прав код. Расхождение кода со спецификацией — дефект, о нём нужно сообщить ([`AGENTS.md`](../../../../AGENTS.md) §3.1). Публичное API и схему зависимостей пакета смотрите в [README пакета](../README.md): здесь они не повторяются.
