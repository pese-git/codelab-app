# Руководство по MCP-клиенту агента

Руководство для разработчика объясняет, как устроен `codelab_agent_mcp` — MCP-клиент Dart-агента: как клиент определяет эпоху протокола и подключается к серверу, как работает streamable HTTP, как коннектор следит за серверами сессии и как инструмент сервера становится инструментом, который видит модель. Прочитав его, вы знаете, куда добавить транспорт, вид блока результата или тест и что делать при типичных сбоях подключения.

Руководство описывает код как он есть. Нормы лежат в спецификациях [`agent-mcp-client`](../../../../openspec/specs/agent-mcp-client/spec.md) и [`agent-tools`](../../../../openspec/specs/agent-tools/spec.md) и в инвариантах [`AGENTS.md`](../AGENTS.md) пакета; если проектные документы расходятся с кодом, прав код. Краткое описание пакета и пример сборки коннектора — в [README пакета](../README.md). Как ядро агента подключает MCP-серверы и показывает их инструменты модели, объяснено в [руководстве по ядру](../../codelab_agent_core/doc/README.md) (глава [06](../../codelab_agent_core/doc/06-tools.md#mcp)); здесь это не повторяется.

## Кому что читать

| Задача | Читайте |
|---|---|
| первый раз открыл пакет | 00, затем 01 |
| не подключается сервер, странный `lastError` | [частые проблемы](05-extending-and-troubleshooting.md#частые-проблемы), 02, 04 |
| сервер не обновляет инструменты | 02 (подписка и `list_changed`), 04 (граница шага) |
| проблема только по HTTP | 03 |
| инструмент пропал или у него странное имя | 01 (проекция), 04 (коллизии) |
| добавить транспорт или вид блока результата | [рецепты](05-extending-and-troubleshooting.md#рецепты) |
| написать тест | [тестирование](05-extending-and-troubleshooting.md#тестирование) |
| подключить MCP-сервер как пользователь | [настройка агента](../../../../docs/user/configuration.md#mcp-серверы), не это руководство |
