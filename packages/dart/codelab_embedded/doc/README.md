# Руководство по мосту встроенного агента

Руководство для разработчика объясняет, как устроен `codelab_embedded`: мост, который собирает ядро Dart-агента внутри процесса клиента и соединяет его с клиентом по ACP (Agent Client Protocol) через пару транспортов в памяти. Прочитав его, вы понимаете, кто что вправе импортировать, чем два открывателя отличаются, как агент открывается, живёт и останавливается и как писать для него тесты и расширения.

Руководство описывает код как он есть. Нормы лежат в спецификации [`openspec/specs/embedded-agent/spec.md`](../../../../openspec/specs/embedded-agent/spec.md) и в [`AGENTS.md`](../AGENTS.md) пакета; общий обзор пакета и схема зависимостей — в [README](../README.md). Сборку ядра и путь запроса руководство не повторяет, а ссылается на [руководство по ядру агента](../../codelab_agent_core/doc/README.md).
